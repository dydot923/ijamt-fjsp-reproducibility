No software license has been selected by the rights holders for this prepared release. Publishing a visible repository and granting an open-source reuse license are separate actions. The preparation process does not grant rights on the authors' or institution's behalf.

If the rights holders decide to use MIT, Apache-2.0 or another license, confirm that the grant covers the relevant code and contributor rights, then add the exact license text in `LICENSE`, update `CITATION.cff` as appropriate, and create a new reviewed release manifest.
