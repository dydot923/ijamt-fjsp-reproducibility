# Data included in this release

## Constructed validation cases

`examples/T1.json` through `T6.json` are generated by `construct()` in `replication/run_exact_oracle.py` with seeds520001-520006. T1-T3 have three jobs of two operations each; T4-T6 have two jobs of three operations each. Each operation has two eligible machines. Processing times and processing-arc energy values are constructed integers. They are not plant measurements or Brandimarte benchmark instances.

`reference/small_instances/` contains their archived exact/reachable fronts and144budget-controlled search records, with three methods, eight seeds and200new evaluations per run. The input generator and independent enumerator are retained so the references can be checked rather than merely trusted.

## Additional data required for the full paper

The code-only distribution omits:

- The frozen E0 engineering input, whose energy fields retain the labels supplied with that input.
- The Mk01-Mk10 third-party routing instances with constructed dimensionless energy extensions.
- The engineering/benchmark confirmation outputs, exploratory results, independent repeated outputs and original comparison sources required by the full auditors.

A complete companion archive, `ijamt-fjsp-data-results-v0.1.0.zip`, restores these files to the original relative paths. E0 and the Mk materials have been approved for redistribution in this release. The archive is attached to [release v0.1.0](https://github.com/dydot923/ijamt-fjsp-reproducibility/releases/tag/v0.1.0) and contains1688manifested files, including original and independently repeated numerical records, diagnostic JSONL files, table snapshots and comparison sources. It also includes a SHA256manifest, version status and dataset metadata. The hosting Release records publication time and download links; no DOI is assigned. A software license does not automatically license the input data; no additional reuse license is assigned by packaging.

After publication, add the actual repository name, versioned Release URL/DOI, version, file hashes and reuse terms here and in the manuscript. Ensure that the data asset is downloadable along with the code before describing the complete reproduction materials as publicly available. The data asset is separated to keep the Git tree small; it is part of the prepared release, not a replacement for public access.

Original Brandimarte source reference:

Brandimarte P (1993) Routing and scheduling in a flexible job shop by tabu search. Annals of Operations Research41:157-183. https://doi.org/10.1007/BF02023073

## Result interpretation

Archived runtimes are machine-specific records, not timing targets for a new machine. The independent2026-11-17 repeated runs do not add independent experimental units to the manuscript's prespecified comparisons. Exact-front certificates cover the six constructed zero-setup, maintenance-free cases, not all possible shop models.
