Initial prepared software release for the manuscript **Objective-matched neighborhoods and exact prefix evaluation for three-objective flexible job-shop scheduling**.

- Verified scheduling, exact prefix evaluation, main/supplementary experimental drivers, analysis and capacity-bound sources.
- Six constructed validation inputs, independent exact-front enumeration and archived small-instance reference results.
- A real200-evaluation example and portable tests, pinned scientific requirements, English/Chinese documentation and citation metadata.

The compact code tree includes constructed validation inputs.
